## 재생성

`generator/` 의 스크립트가 원본 양식 파일(`제1회 연구소기술경진대회_...251030.pptx`)을
템플릿으로 읽어 본문 슬라이드를 다시 생성한다.

```bash
pip install python-pptx
python generator/build.py 출력경로.pptx   # build.py 의 SRC 를 양식 파일 경로로 지정
```

사진 두 장은 `generator/assets/` 아래에 두고 원본 그대로 배치한다.

| `panel-detail.png` | 1066×416 | 15번 슬라이드 · 리포트 그림 8-2 — 촬상 영역 단면 상세와 실제 촬상 이미지 |

노란 모듈 상면이 평탄부, 모듈 사이 간극이 딥이며, 11절 로그의 「평탄부 5 · 딥 4」
반복 패턴이 이 물리 형상의 시간축 표현이다.

6번 슬라이드는 프로브 원뿔 꼭짓점(이미지 높이의 6.57 %)과 광학 헤드 초점면(12.9 %)을
같은 높이에 두고 점선으로 잇는다. 16번 슬라이드의 「평탄 1~5」 위치는 파형 픽셀을
스캔해 얻은 이미지 폭 대비 25.27 / 34.48 / 42.23 / 49.95 / 58.25 % 다.

주의 — 남겨 둔 '감사 합니다' 슬라이드가 `slide21.xml` 을 점유하므로, 본문을 20장 넘게
추가하면 python-pptx 가 같은 파트 이름을 다시 배정해 슬라이드가 덮어써진다.
`build.py` 는 그 파트를 `slide900.xml` 로 미리 옮겨 충돌을 막는다.

차트는 PowerPoint 네이티브 차트라 발표 중에도 데이터 편집이 가능하다.
